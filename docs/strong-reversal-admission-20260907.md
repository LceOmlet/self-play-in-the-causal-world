强反转接受条件的因果值范围化简

基线：`aa86218d0280b8abdfd34bdc07788501cad17d10`。本项归入持续 goal 的 C/C2。
目的为省去必然失败候选的观察推断，保持当前完整提案分布及接受事件。

对固定世界、动作变量 X、目标事件 Y=y，记

\[
v_a=P(Y=y\mid do(X=a)),\qquad R=\max_a v_a-\min_a v_a.
\]

设 O 是观察条件概率的全部最优动作。最大化任务的原接受损失为
`max(v) - max(v[a] for a in O)`；最小化任务为
`min(v[a] for a in O) - min(v)`。两者均满足 `0 ≤ loss ≤ R`。
这对任意非空 O 成立，包括观察并列最优、因果并列最优及两者相交。
因此，若当前槽要求强反转且 `R < τ`，原条件
`discordant and loss >= τ` 必为假，无需计算 O。
这里的 `τ = 2 / sqrt(2048)` 保持原值，等于阈值时仍需继续推断。
一致槽只要求非反转，不能据此范围提前拒绝。

改动从原关系函数提取完全相同的干预值计算和观察关系计算，新增接受谓词。
完整关系函数继续返回真实的 `(discordant, loss)`，包括低于阈值的弱反转。
仅生成器的接受谓词在必要条件失败时退出；需要观察结果时，复用已有因果值，
不重复执行干预推断。查询计算、CPT、角色、采样随机调用、提案种子映射和接受阈值
均沿用原实现。数学范围界没有使用未知观察最优动作、独立分层或经验阈值。

数值方面，范围使用 `float(max(values) - min(values))`。原损失也在对应差值后
转成 float。对有限 binary64 值，固定最大值或最小值的浮点减法具有单调性；
对 Fraction，先有精确差值的偏序，再经单调的 float 舍入。因此计算出的原损失
仍不大于计算出的范围。不能用另一个近似 CPT 强度界直接替换它并声称等价。
本证明针对现有合法输入及观察动作均有正概率的契约；没有扩展零概率动作条件值的定义。

采样律保持也有逐步证明：每个提案的原、新接受布尔值相同；执行的所有随机调用
相同。故在第一次接受之前，拒绝次数与下一提案索引归纳地相同，最终世界、角色、
状态、预算和输出逐项相同。该化简减少一次候选检查的成本，**不提高接受概率**，
也不消除强反转条件对最终结构/CPT 分布的偏移。

独立参照测试直接枚举三节点有理数联合分布，覆盖 64 个正动作概率世界、二至五个
动作、两个目标事件、两种目标方向、Fraction 与 binary64 输入及接受阈值的相邻
浮点数。另验收弱反转仍被报告但强反转拒绝不调用观察推断，以及观察并列最优的
一致槽。`independent-tests.log`：3 项测试、3,344 项子测试通过。

完整生成比较从 Git 基线提取原 `iter_sampled_seeds` 和原关系函数，不手写一个相似
基线。比较两次执行并交换顺序，检查完整输出（包含 CPT）与完整世界提案序列严格相同，
统计实际观察/干预查询次数。该审计替换仅在独立比较进程生效，不进入训练运行时。
执行程序及结果见 `research/strong_reversal_admission_20260907`。
