对整个 CPT-World 强化学习任务的判断，2026-09-08

目前应继续训练，主要投入任务价值、有效学习信号及其中影响大、能够明确改进的问题。现有证据没有证明整个环境无价值或官方 DAPO 正在错误更新，也没有显示整体学习收益。证明严密不能替代全局影响判断；耗时高也不能替代可改进性判断。两者都不应把工作重新带回局部反例或微优化。

| 全局目标 | 现有证据意味着什么 | 现在改变的决策 |
|---|---|---|

上述证据不能混成一个总体百分比。174/180 是经过动态筛选的训练轨迹；基座／第 25 步是同一组 25 道贪心验证；57/80 来自 40 个冻结强反转世界的两条采样带；23/74 是计算核冻结验收集。它们各自说明完成行为、同题能力、基线解释或真值覆盖，不能相互替代。

已有 250 个生产世界的诊断也不支持“整个环境都被常数答案解决”：ATE 零答案质量达到 0.9 的只有 4/50，反事实零区间达到 0.9 的为 0/50；后门空集平均质量虽高但合法率仅 12/50，中介空结构质量为零。合法有限策略在多个家族优于固定答案，说明存在信息利用的价值。最优干预部分必须使用更强的观察排名基线重新解释，不能套用原弱对照。这些既有结果见 `task-value-and-learning-priority-20260907.md`，不是本轮重采样，也不证明 LLM 已经能够学会这些程序。
