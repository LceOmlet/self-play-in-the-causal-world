真实最优干预任务：合法实验的信息收益与剩余学习缺口

本轮复用已有 50 道最优干预题（10 道一致、40 道强反转），每题两条原有采样带。只读公开提示与合法反馈的实验策略，把最优动作正确率从观察基线的 23% 提高到 70%，平均绝对遗憾从 0.07870 降到 0.02115。强反转层的正确率从 3.75% 提高到 63.75%。这提供了真实任务中因果信息有用的证据，不支持通过削弱强反转条件来改善表面成绩。

这不是模型训练结果。策略使用 NumPy 做统计和计数，而且完整记录中有 41/100 超过当前模型的 32K 上下文。不能把手写解题能力当成官方 DAPO 的学习能力。本轮没有启动模型更新，没有改任务生成、预算、奖励或官方 DAPO 实现。

解题路径及其成立条件

公开协议使 X、Y 不可操纵，其余节点可以分别干预。若 Z 不是 X 的祖先，改变 `do(Z=z)` 不会改变 X 的边缘分布；因此不同干预状态下 X 的响应差异是上游信息。反过来，边缘不变不保证没有因果路径，路径抵消与有限样本误差都可能造成漏检。此次筛选只是诊断策略，不声称在无 faithfulness 假设下精确恢复祖先集。

若一个集合 S 包含 X 的所有父节点且只含 X 的非后代，则它阻断所有后门路径：任一路径的首个父节点是已条件化的非碰撞点。完整祖先集是满足这一条件的集合之一。因此在合法调整集上，

`P(Y=y | do(X=x)) = Σ_s P(Y=y | X=x, S=s) P(S=s)`。

这一公式提供了明确的因果信息使用路径。它不是把观察最优动作换个名字；权重从 `P(S | X=x)` 变为 `P(S)`，消除了对应的混杂。独立的有理数 Simpson 表中，观察值为 `[0.27, 0.73]`，调整值为 `[0.55, 0.45]`，动作排序相反；公式和重标号检查均通过。

预先固定的诊断方法

- 四分之一标量预算用于全部合法单点干预，各干预状态测量 X；沿用前次后门基线的 3,999 次池化多项式 bootstrap 和 `0.05 / 合法目标数` 阈值。这不是精确的有限样本显著性保证。
- 对筛选出的 S，使用余下预算观察 `[X,Y,S]`，按后门公式标准化。条件分布使用每个结果状态 0.5 的平滑。没有依据答案调筛选阈值、分配比例或平滑参数。
- 每个命令都实际经过生产 `WorldSpecEpisode.step`，遵守标量收费、不可操纵锚点和 128 行反馈限制。策略函数只接收公开提示与反馈回调。
- 完整答案先写入不可见真值之外的公开轨迹文件，再查看真值。100 份公开记录均通过不加载世界、CPT 或真值的策略重放，命令及答案逐项相同。隐藏图只用于提交后的合法调整集判断和误差诊断。

失败已定位到更具体的环节

100 条轨迹中，81 条选出的集合经真实 DAG 的精确后门判据确认合法。30 条最终错误里，24 条已经有合法调整集，只有 6 条的调整集不合法。这 24 条不能归因于调整集违反后门条件；其误差产生在后续有限样本标准化及平滑估计中。仍不能据此认定环境预算在所有策略下不足：集合可能冗余，实验设计和估计器也不是最优的。

一个有代表性的实际失败是 `SAMPLED-45024753412-best_intervention-decision-a1`。两条轨迹均选中合法的两变量集合，均收集 27,649 个联合观察单位；但最优动作在约 49.7% / 42.0% 的经验调整权重上没有对应样本，最终动作遗憾为 0.18453。这不是人为构造的微小差值反例。接下来应检查其实际 CPT、必要调整变量及合法干预如何影响这些状态组合的覆盖，区分冗余条件化、被动抽样不足与机制造成的困难。

本轮已经进一步核对该题的实际机制：`Pa(X)={DVR,POF}`，`Pa(Y)={X,POF}`。因此 `Y ⟂ DVR | X,POF`，而 POF 是 X 的非后代，单独调整 POF 就合法。DVR 对 X 的因果作用不意味着它必须作为 Y 条件分布的独立分层。把原样本的 DVR 分层合并后，估计所用分层由 16 降至 4；一条轨迹改为正确动作，另一条仍错误。这是提交后使用真实父集作的诊断，不能计入 70% 的公开策略成绩。

同一机制还解释了工具开销：测量 `[X,Y,DVR,POF]` 有 144 种联合状态，受 128 行限制需要把 27,649 个单位拆成 217 次观察；只测 `[X,Y,POF]` 有 36 种状态，原协议允许一次请求这些单位。这不需要放宽反馈限制，只需要识别并使用正确的条件独立性。

余下困难也不应直接归于不可判别。对最优动作在 `POF=state_1` 的关键结果机制行，已枚举全部 38 种合法单点干预与自然观察，并计入已知干预目标无需测量的实际收费。每个标量得到该行 Y 样本的总体概率，自然观察为 `4.82128e-5`；最优的 `do(DVR=state_0)` 为 `5.58156e-4`，约为 **11.58 倍**。因为 Y 的父集只有 X、POF，这项干预下观测到的条件 Y 机制仍是所需机制。这里证明/计算的是该行覆盖的最佳单次实验，不是整个任务的全局最优策略；选择使用了提交后揭示的模型，不能冒充模型已经学会实验设计。源数据见 `overlap-case.json`、`mechanism-pooling.json`。

同时用当前 Qwen3.5-9B tokenizer 对全部轨迹作只含命令和工具反馈的聊天模板重建。41/100 超过 32,768 token，最大为 200,909。重建省略模型的推理文字，也不是一次实际 verl rollout；它只能说明这套完整采样策略的部分记录不适合当前模型上下文，不能证明别的合法策略也不适合，更不能直接推出应扩大上下文或放宽任务。

因此，后续 B/E 验证必须让真实模型在原协议和实际上下文内完成实验，比较原始基座与官方更新后的真实任务误差。C/D 的根因工作优先跟进已经观察到的覆盖困难及冗余调整，避免再次用罕见构造取代实际困难的诊断。A/A2 的剩余联合响应认证任务继续保留。

两项审计错误与修正

初次运行复用了旧冻结概率缓存，而评分器重算当前候选概率。最大差异只有 `2.22e-16`，最优动作没有变化，但混合数值来源使部分归一化遗憾越界，15 条终局评分报错，一些原本最优的答案也未被标为严格零遗憾。原始结果全部保留，不能引用其最优率。当前正式最优干预训练行不缓存这类概率；这不是当前训练中新发现的 15 次故障。

已改正诊断 runner，保持原冻结世界及采样带，按当前环境路径评分，不混用旧概率缓存。100 份已锁定答案全部由同一当前生产评分路径重新评分；对照方法也统一如此处理，没有重选答案或丢弃失败。另将一条原失败轨迹完整重跑通过，公开命令与反馈哈希完全相同。没有在奖励器中夹紧数值、放宽检查或变更奖励定义。

初次上下文计数误取 tokenizer 返回字典的字段数，得到无效的 2。该文件明确以 `context-initial-invalid.json` 归档；已改为计数 `input_ids`，并检查输入类型和非平凡长度。上述 41/100 来自修正后的实际 token 序列。
