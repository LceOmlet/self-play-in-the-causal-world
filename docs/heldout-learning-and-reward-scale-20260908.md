后门奖励与官方优势的关系

对已经完成答案、没有长度惩罚的后门轨迹，当前生产奖励为 `q_i = 1 - d_i/14`，其中 `d_i` 是到合法调整集的最小编辑距离，14 来自原任务支持的最大节点数 16 减去两个端点。官方 GRPO 使用样本标准差和 `epsilon=1e-6`：

`A_i = (q_i - mean(q)) / (std(q) + epsilon)`

代入得到精确关系：

`A_i = -(d_i - mean(d)) / (std(d) + 14*epsilon)`。

因此分母 14 只通过稳定项影响归一化后的优势，没有使整个优势缩小 14 倍。与把 `-d_i` 送入同一官方函数的结果相比，绝对差由

`abs(d_i-mean(d)) * 13*epsilon / ((std(d)+14*epsilon)*(std(d)+epsilon))`

给出；浮点执行另有舍入差。若同组所有编辑距离相同，原奖励与负距离都没有组内信号，动态过滤对这一仿射变换也不改变去留。不能靠把奖励数值展开来解决同组答案一致的问题。

实际对照取冻结第 1、2、12、15 步的 16 条后门轨迹，按原始环境事件中的真实编辑距离核对奖励，然后直接调用固定官方 `compute_grpo_outcome_advantage`。FP64 与上述代数式最大差约 `1.61e-15`；FP32 中原奖励优势与负距离优势的最大差为 `4.02e-5`，符合稳定项和舍入差范围。例如第 2 步编辑距离 `[3,3,2,3]`，实际质量 `[11/14,11/14,12/14,11/14]`，官方优势约为 `[-0.5000,-0.5000,1.5000,-0.5000]`，更接近合法集的答案仍获得明确正优势。

这里是实际官方函数的 CPU 标量奖励对照，不是完整 GPU loss 重放。第 17 步含未完成答案，已排除；没有给缺失的环境编辑距离编造值。长度惩罚会破坏上述单一仿射关系，不能把结论扩展到有惩罚的题组或其它非线性奖励家族。本轮没有替换训练奖励。最小期望编辑距离与最大合法解率也是不同的统计目标，不能用本项等价关系宣称二者一致或模型必然学会。

原始奖励对合法率的约束也可直接推出。合法答案质量为 1，完成但不合法的答案至多为 13/14，未完成答案为 0。若平均原始质量为 Q、合法完成概率为 p，则必有 `max(0,14Q-13) <= p <= Q`。因此 Q=0.9 本身只约束 p 在 `[0,0.9]`，不能推出很高的合法率；只有 Q 超过 13/14 时才给出正的下界。这是原评分定义的数学关系，不是新增训练阈值，亦不把有限样本均值当作总体期望。它说明必须保留严格成功指标，但没有证明当前奖励的全局策略偏好与合法率等价。
