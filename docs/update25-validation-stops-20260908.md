长度限制的直接证据

当前官方响应上限 M=30720，长度惩罚缓冲 B=4096，惩罚因子为 1。固定官方 `DAPORewardManager` 使用响应 attention mask 的长度 L，含工具文本；它不只统计模型动作 token。实际公式为：

`p = min(-(L - 26624)/4096, 0)`。

当记录的 p<0，可唯一反解 `L = 26624 - 4096*p`。这些值是整数与二的幂分母构成的精确 FP32 数值，不能把由该公式恢复的 L 描述成对解码文本重新分词得到的近似值。p=0 时只能得出 L≤26624，不能恢复准确长度。官方文本 dump 已去除部分特殊 token，未保留原始 token ID。

11 条未完成输出的 p 均为 -1，因此 L 恰为 30720。官方 `_handle_generating_state` 在合并生成 token 后先检查响应长度；达到上限就结束，随后才会进入工具调用提取逻辑。这 11 条包括一条尚未写完的新工具调用，以及十条仍在自然语言推理中的输出。实际原文存在反复重述和推测，未形成终止答案。
