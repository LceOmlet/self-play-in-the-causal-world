# Optimization goal

Increase exact or epsilon-sharp closure of individual-counterfactual tasks on
the frozen distribution cohort without changing CPT-World generation,
task/query/reward semantics, the compatible Markovian SCM set, numerical
tolerances, fallback behavior, or the five-second allowance for each endpoint.

An optimization is admissible only when it is supported by aggregate profiler
evidence, applies to a complete relabeling- and graph-isomorphism-invariant
instance class, agrees with the exact owner on tractable cases, increases the
distribution closure rate above 23/30, and does not reduce formal-regression
closure. Seed IDs, variable names, topology strings, CPT fingerprints, and
finite failure lists are forbidden as implementation triggers.
