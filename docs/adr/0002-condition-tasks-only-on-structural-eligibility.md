# Condition each task only on structural eligibility

A sampled DAG may instantiate a task only when the graph contains the
relationships required to define that task. For example, a mediator-structure
task requires an indirect directed treatment-to-outcome path. Consequently,
each task family may induce its own structure distribution by conditioning the
shared world prior on this eligibility event.

This is the only task-specific acceptance condition at this stage. Sampling
must not accept or reject a world using effect magnitude, answerability
diagnostics, model performance, or intended difficulty. Those quantities may
be measured later without changing the generated distribution.
