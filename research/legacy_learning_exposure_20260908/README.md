旧训练前 800 步：补齐范围，收束错误归因

此前分析主要使用恢复后的 251–899 步日志。本目录保全旧 checkpoint-850 的 trainer_state，并取连续第 1–800 步重新核对。它用于诊断旧实验，不恢复旧检查点，也不将旧实现视为当前官方 verl DAPO 的能力证据。早期审计已经发现大部分现象；本次增量是补齐原先遗漏的 1–250 步及准确统一范围，不是新发现一个训练故障。

每步一个题组、四条轨迹，共 800 题组、3200 条轨迹，每家族 160 组。历史源码对采样索引递增，未发现明显种子重复机制；缺少逐题身份日志，不能把曝光数称为独立世界数。

早期为第 1–200 步，后期为第 601–800 步，各家族每窗口 40 组。数值误差按有效终局数加权，RMSE 先汇总 MSE 再开方；不得直接平均每组 RMSE。两个窗口是不同训练世界和采样策略，不能据此确认因果学习收益或退化。有效终局只表示进入误差统计，不表示答案正确。中介得分不等于整题严格正确率。

总计 124/800 组零梯度，均与零奖励标准差对应；非零奖励差异却零梯度为 0 组。全部 3200 条轨迹仅记录 13 条长度截断。没有有效终局的原因不能一概算作长度截断；零当前梯度也不意味着 Adam 动量不更新参数。

对项目决策的影响

这些数据不支持把旧停滞统一解释成普遍无区分信号、普遍做不完或参数完全不更新。不同家族变化不一致，应表述为缺少全面、稳定的能力改善证据，不能说所有家族完全没有改善迹象。

目前仍没有找到主导学习障碍。非零梯度不证明有效方法获得强化；错误推理偶然答对、得到正优势，也不证明终局奖励在期望上偏好错误方法。旧日志缺少逐轨迹实验、答案、奖励和权重的联合记录，不能从本表追溯哪种方法得到强化。已有当前轨迹中的同类错误样例已经足够，不再靠扩充例子冒充根因定位。

当前 BF16 adapter 现象与旧 FP32 训练不共通，已独立收束。公开权限及反馈实现中未发现新的信息漏传；合法有限程序的计算量不能直接推导所有有效解法都需要同样资源。这些候选目前均不足以支持新的生产修改。训练继续，额外模型验证保持关闭。
